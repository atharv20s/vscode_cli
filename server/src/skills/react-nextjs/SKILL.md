# React and Next.js engineering

Inspect package.json, lockfiles, existing routing, styling and component conventions before editing.

- Reuse the project's framework, package manager and design system.
- Build accessible, responsive UI with semantic HTML, keyboard support, useful loading/empty/error states and form validation.
- Keep components focused; separate data access and business logic from presentation.
- In Next.js, respect the repository's App Router or Pages Router and server/client component boundaries.
- Never expose secrets or privileged API credentials in browser bundles.
- Install only necessary dependencies and use the existing lockfile/package manager.
- Run the project's lint, typecheck, test and production build scripts when present.
- Start the development server and verify the actual preview URL when preview tools are available.
